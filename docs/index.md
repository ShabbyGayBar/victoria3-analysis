# Playing Victoria 3 with scripts and excel tables

This project extracts Victoria 3 game definitions into human-readable tables and figures.

But visualizing game concepts is only the beginning: the true purpose is to:

- build a mathematical model
- translate your game objectives into mathematical language
- solve for an optimal solution that guides your gameplay.

And you not only get to see **how**, but also get to see **why**:

- the marginal value of each building level
- the bottlenecks in your supply chain
- the trade-offs between different production strategies,

all without even installing the game.

## What the project covers

<div class="grid cards" markdown>

- **Parse game data** — Buildings, goods, production methods, technologies,
  population needs, and state-region resources become pandas DataFrames.
- **Model an economy** — Translate building levels into goods flows,
  employment, wealth, GDP, and nominal or market prices.
- **Optimize production** — Express objectives and constraints in a reusable
  `Scenario`, then solve them with SciPy's linear programming tools.
- **Trace supply chains** — Visualize upstream dependencies, attribute value
  added, inspect bottlenecks, and compare scenario sweeps.

</div>

## Install

=== "Released package"

    ```bash
    pip install "https://github.com/ShabbyGayBar/victoria3-analysis/releases/download/v0.1.0/vic3_analysis-0.1.0-py3-none-any.whl"
    ```

=== "Development checkout"

    ```bash
    git clone https://github.com/ShabbyGayBar/victoria3-analysis.git
    cd victoria3-analysis
    uv sync
    ```

Python 3.13 is required. Parsing fresh data also requires a local Victoria 3 installation; although analyses based on the [committed tables](showcase/parsed-data.md) can be explored without one.
