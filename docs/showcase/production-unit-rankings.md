# 生产单元排行榜

在维多利亚3的论坛上，“最强建筑”往往为玩家们津津乐道。根据语境和侧重的不同，结论也通常莫衷一是。是汽车大人？还是工具大人？还是种植园？还是某位神秘世外高人？这次就让我们在 AI 大人的帮助下彻底终结这个话题。

## 什么是生产单元？

游戏中包含 115 种建筑。每个建筑有若干不同的生产方式。这样，游戏中所有可能的建筑加生产方式组合达到了 1,638 种，我们将其称为**生产单元**。排除奇观、军队、政府、自给农业、公司总部等建筑，共有 1,274 个值得排名的生产单元。

生产单元决定了输入和输出商品，以及雇佣的人力，提供或消耗的基础设施和建筑力等。

## 分析口径

在继续下一步之前，首先让我们做一些必要的假设。
1. 市场采用合作社所有制。各生产单元没有人力成本。单元生产商品总值减去单元建筑购买商品总值作为净利润全部直接分红给员工。
2. 市场没有本地市场火星损耗。
3. 忽略市场价格机制，所有商品采用基础价格。这也是最偏离游戏的假设，因此基于这个假设得到的所有指标我会加上“名义”这个前缀来区分。
4. 忽略吞吐量机制，如轧棉机，公司，规模效应等。

有了这些信息，我们可以推算一些我们作为玩家感兴趣的指标。

设一个生产单元的输入商品基础价格总值为 I，输出商品基础价格总值为 O，雇员人数为 L，所需建筑力为 C，则：

- **名义净利** = O − I
- **名义人均净利/产值** = (O − I) ÷ L
- **每点建筑力名义净利** = (O − I) ÷ C

名义净利对应大家熟悉的产值；名义人均净利则对应大家熟悉的人均产值；每点建筑力名义净利与扩张速度和回本周期直接相关。商品流量和名义净利均按周计算；名义净利及人均、每建筑力指标可乘以 52 换算成年值。

!!! note "排名规则"

    排名不包含奇观、军队、政府、自给农业、公司总部等非一般商品生产建筑，只保留具有正产出、正就业、正建筑力成本和正名义净利的生产单元。排名对象是生产单元而不是建筑，所以同一建筑的多套生产方式可以同时进入前十。指标相同时，以名义净利更高者优先。

在 AI 的帮助下，我们得到了这张[表格](../tables/production_table.csv)，收录了所有生产单元的以上相关信息。让我们根据不同指标排序，看看游戏中有哪些最强生产单元。

## 尾盘

尾盘排名允许所有生产方式。考虑到后期不在乎回本周期，每点建筑力名义净利就不进行排名了。

万万没想到，有口皆碑的汽车大人，在前十只能垫底。而真神其实也不是我们的武器厂，而是一位世外高人。没错，就是哈瓦那大剧院！区区200学者就能产出5个艺术品，人均高达3.5，可谓一骑绝尘。此外，木制车厢的人均居然超过了科技要求更高的钢制车厢，不得不怀疑P社是否填错了数值。

那么汽车作为人均产值并非最为突出的生产单元，为何会被称为神？无他，唯需求大耳。汽车不仅能满足休闲需求，还能满足自由出行需求，并且在自由出行中的最大供应占比达到 100%；轻武器只能进入休闲需求，适用范围窄得多。火炮则是纯军需品。铁路问题在于运力是本地商品，基本卖不出去。至于硫矿和油井，则是作为资源存在上限。

从这个榜单可以看出几个趋势：
- 自动化越激进，人均产值越高。前十生产单元的劳工数量没有超过1,000人的，甚至有些根本不招工人。
- 没有石油，就没有高人均。除了油井，所有前十生产单元都可以说是油老虎。

综上所述，作为人均GDP追求者，最优解其实就是让全国只有一块地，上面盖70座油井或硫矿，同时统御一个巨大的市场，给自己提供名贵工具引擎和消费品。

如果玩家很缺建筑力，只要200锤的种植园几乎是唯一答案。而糖料种植园更是个中翘楚，前十名中居然九个是它的不同生产方式的排列组合，剩下一个是茶叶种植园。但不难看出，流水的生产方式，铁打的鞭子。鞭子好啊，鞭子得抽啊。

如果不抽鞭子，原榜首糖料种植园直接跌至 9.60，下降约 38.5%。而采用电动卷烟机和工厂收音机的烟草种植园则以 11.40 的指标拿下榜首。

到目前的榜单为止，速B也许会看一看，但对于大多数玩家来说，可能并没有种植园可以造，或者玩家想要工业化，而不是把建造力泼在农业上。因此我们追加下面的榜单，只统计工业建筑，看看工业建筑中哪些生产单元回本最快。

食品厂以 4.42 夺冠。不过它同时使用七种投入，并产出 150 单位食品和 100 单位烈酒。烈酒在这里是必要的，它贡献了这个方案总产值的 40%。如果关闭酿酒生产，食品厂的最佳指标会降到 3.33，掉出前十。

工具厂和火炮厂并列第二，余下的则是家具纺织等轻工业和武器厂等军工业。值得注意的是，榜单完全被 600 锤的轻工业和军事工业垄断，而需要 800 锤的化工厂、钢铁厂、发动机厂等重工业无一上榜，毕竟即使重工业的产值不低，除以建筑力后也很难进入前十。

另一个反直觉结果是手工装配大获全胜。工艺装备工坊使用手工装配时为 4.17，换成水管锅炉降至 3.67，换成旋转阀发动机又降至 3.42；火炮铸造厂也从手工装配的 4.17 降到旋转阀发动机的 3.42。这并不表示自动化没有价值，而是因为当前模型不计算工资：自动化减少的雇员在这个指标里不值钱，额外消耗的煤炭和工具却会直接减少名义净利。

## 总结

纵观四张榜单，我们可以看到，除了跟种植园拼建造力，工具厂和军工厂都能勇夺头筹。左手高产值，右手低雇员。这其中工具的需求又奇高，因此称其为游戏中最夯建筑也不为过。

但值得注意的是，这四张榜单仍然只算了每栋建筑内部的账。每个生产单元表现如何是一回事，其所在产业上下游如何又是另一回事。工具厂这么强，那么会不会被上游的钢铁厂和橡胶园拖累呢？
