    English · 简体中文

    财富等级 vs 政治力量¶

    从1至99可大致分为3段。

    • 20级以下增长较快，但每级增幅并不固定。
    • 20—49级呈分段线性增长，每级增加的点数逐步提高。
    • 50级起线性增长：财富涨一级，政治力量增加25点。

    名词解释¶

    • 需求大类，即 BV1pG3yzVE67 中的“消费组”。
    • 消费额，即每张图的纵轴，为每10,000名劳动人口在该需求大类上的每周基础价格预算，并非实际市场支出或商品数量。受扶养人口的基础消费权重为劳动人口的一半。
    • 财富等级，即每张图的横轴，决定了一个人每周的消费总预算是多少。当收入无法负担当前消费组时，财富等级会下降；能够负担更高等级的消费组时，财富等级会上升。与生活水平（SoL）强相关但不相等。

    复现¶

    在项目根目录运行：

    uv run python -m examples.parse

    环境准备与游戏文件定位见解析指南，字段口径见消费组数据字典。本文数据版本为1.13.11，重新生成的结果取决于本地安装的游戏版本。
